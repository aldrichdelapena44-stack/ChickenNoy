🚀 RENDER.COM SETUP (Backend):

□ 1. Sign up at render.com with GitHub
□ 2. Click "New +" → "Web Service"
□ 3. Connect GitHub repository (or upload code)
□ 4. Set Name: chickennoy-backend
□ 5. Set Environment: Node
□ 6. Set Build Command: npm install
□ 7. Set Start Command: npm start
□ 8. Choose Free plan
□ 9. Add Environment Variable: MONGO_URI
□ 10. Add Environment Variable: PORT = 10000
□ 11. Add Environment Variable: JWT_SECRET
□ 12. Click "Create Web Service"
□ 13. Wait for deployment (5-10 minutes)
□ 14. Copy backend URL: _________________________________

═══════════════════════════════════════════════════════════════

🗄️ MONGODB ATLAS SETUP (Database):

□ 1. Sign up at mongodb.com/cloud/atlas
□ 2. Create new project: ChickenNoy
□ 3. Build a cluster (FREE M0 Sandbox)
□ 4. Choose AWS provider
□ 5. Choose closest region
□ 6. Name cluster: ChickenNoy
□ 7. Create Database User:
    Username: chickennoy
    Password: _________________ (save this!)
□ 8. Add IP Address: 0.0.0.0/0 (allow from anywhere)
□ 9. Click "Connect" → "Connect your application"
□ 10. Copy connection string
□ 11. Replace <password> with your actual password
□ 12. Add to Render environment variables

═══════════════════════════════════════════════════════════════

🔗 CONNECT FRONTEND TO BACKEND:

□ 1. Visit your InfinityFree site
□ 2. Add ?apiBase=YOUR_BACKEND_URL to URL
    Example: https://yoursite.infinityfreeapp.com/?apiBase=https://chickennoy-backend.onrender.com
□ 3. Verify it saved (check localStorage in browser console)

OR

□ 1. Press Ctrl+Shift+D on your site
□ 2. Enter backend URL
□ 3. Click OK
